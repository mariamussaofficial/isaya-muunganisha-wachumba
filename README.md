# Isaya Muunganisha Wachumba

Production foundation for Isaya Muunganisha Wachumba, a Tanzania-focused digital media publication covering news, trends, social media, entertainment and life.

## Stack

- Astro
- TypeScript
- Cloudflare Pages
- GitHub
- Static-first, SEO-first architecture

## Local development

```bash
npm install
npm run dev
```

## Cloudflare Pages

Build command: `npm run build`

Build output directory: `dist`

Before deployment, replace `YOUR-DOMAIN.xyz` in `astro.config.mjs`, `public/robots.txt`, and the contact/SEO placeholders with the official domain and verified editorial contact details.
